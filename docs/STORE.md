# 小程序上架资料

## 图标

| 文件 | 用途 |
| --- | --- |
| `assets/icon-upload-1024.png` | 1024×1024 满版母版（无透明角），改图用 |
| `assets/icon-144.png` | 公众平台上传用，144×144，PNG |
| `assets/icon-1024.png` | 带圆角的品牌版，用于 README / 宣传图 |
| `assets/icon-rounded-144.png` | 圆角版 144px |
| `assets/icon.svg` / `assets/icon-upload.svg` | 矢量源文件，可改色/改元素后重新导出 |

设计含义：蓝色日历 = 排班表；橙色格 + 时钟 = 已确认的班次与上班提醒。无文字、无字体依赖，小尺寸下仍清晰。

上传要求：PNG/JPG，144×144，小于 2MB；微信会自动裁成圆角。若平台提示透明背景问题，用 `icon-144.png`（满版）。

## 简介（平台「小程序简介」字段）

微信简介限制约 4–120 字符，挑一版直接填：

**标准版（推荐，约 70 字）**

> 从聊天记录中选择排班图，自动识别成电子班表；管理员核对后按周发布，员工只看到自己的班次，并能将上下班时间添加到手机日历，提前 30 分钟提醒。

**简短版（约 36 字）**

> 排班图一键识别，按周发布；员工查看个人班次，并添加手机日历提醒。

**完整版（约 97 字，适合审核说明）**

> 支持从聊天或相册选择排班图，识别团队周班表；管理员校对异常、预览差异后按周发布；员工查看本人班次与调班变化，可将单条班次加入手机日历并在上班前 30 分钟提醒。原图仅管理员可见，默认保留 7 天。

## 一句话卖点

> 把群里的排班图，变成每个人手机里的班表。

## 隐私保护指引必须声明

| 接口 | 声明内容 |
| --- | --- |
| `wx.chooseMessageFile` / `wx.chooseMedia` | 选择图片，用于识别排班表 |
| `wx.addPhoneCalendar` | 写入系统日历（仅写入，不读取/修改/删除） |

不声明这两项，真机上相关接口会被微信拦截。

## 审核注意

- 名称、简介、类目与实际功能保持一致，不要写成「排版」类工具。
- 简介里不要放联系方式、外部链接、诱导分享或「最」类绝对化用语。
- 排班原图属于用户上传内容，需在隐私指引中说明用途、保留期限（默认 7 天）和可见范围（仅管理员）。
- 上线前完成小程序备案。
